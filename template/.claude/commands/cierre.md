---
description: Ritual de cierre de sesión — resume lo hecho y actualiza el estado del proyecto
---

Cerrá la sesión de trabajo dejando todo documentado para la próxima vez.

Hacé esto en orden:

1. **Resumí la sesión** en el chat: qué se hizo, qué quedó a medias.

2. **Actualizá `docs/estado/PROGRESO.md`** → agregá una entrada NUEVA al INICIO
   del archivo (lo más reciente arriba), con este formato:
   ```
   ## [FECHA] — [título corto de la sesión]
   - [qué se logró]
   - [qué quedó pendiente]
   ```

3. **Actualizá `docs/estado/RESUMEN.md`** → reflejá el estado actual real del
   proyecto (reemplazá lo viejo, este archivo es una foto del ahora, no historial).

4. **Actualizá `docs/estado/PENDIENTES.md`** → sacá lo que se terminó, agregá lo nuevo.

5. **Verificá si hay que commitear.** Si hay cambios sin guardar, ofrecé hacer
   un commit con un mensaje claro. NO commitees sin que el usuario confirme.

6. Cerrá proponiendo un nombre corto para la sesión (para el commit/bitácora).

Importante: usá la fecha real de hoy. No inventes datos de lo que se hizo.
