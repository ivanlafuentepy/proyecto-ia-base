# Mi Proyecto

> Proyecto creado con **Proyecto IA Base**.
> Si todavía no lo configuraste, abrí esta carpeta en VS Code y escribí `/configurar`.

## Comandos útiles

- `/configurar` — cargá los datos de tu empresa (hacelo primero)
- `/contexto` — mirá en qué estás
- `/cierre` — cerrá la sesión guardando el avance
- `/verificar` — chequeá que algo esté bien antes de darlo por listo

## Dónde está cada cosa

- `CLAUDE.md` — el cerebro de tu proyecto (quién sos, qué hacés, las reglas)
- `.claude/agents/` — tu equipo de agentes
- `docs/estado/` — el estado y la bitácora del proyecto
- `.env` — tus claves secretas (NUNCA se sube a git)
